# CPS234 Compliance Toolkit

## Purpose

This starter toolkit provides templates for assessing APRA CPS 234 information security obligations, mapping controls, and organising evidence.

## What is APRA CPS 234

APRA CPS 234 is an Australian prudential standard focused on information security capability, control effectiveness, incident response, and oversight of information assets, including those managed by third parties.

## Key Obligations

- Maintain information security capability commensurate with threats and asset criticality.
- Define clear roles and responsibilities.
- Identify and classify information assets.
- Implement controls to protect information assets.
- Test control effectiveness.
- Manage information security incidents.
- Notify APRA of material incidents and control weaknesses where required.
- Oversee third-party and related-party security arrangements.
