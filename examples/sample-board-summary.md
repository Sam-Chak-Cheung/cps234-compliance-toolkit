# Sample CPS 234 Board / Risk Committee Summary

## Purpose

This sample provides a concise format for communicating CPS 234 assessment themes to senior stakeholders.

## Current View

The organisation has a defined information security policy framework and several implemented technical controls. The main improvement opportunity is to strengthen evidence quality, control ownership, testing cadence, and third-party assurance tracking.

## Key Observations

| Area | Sample Observation | Risk Theme |
| --- | --- | --- |
| Information asset identification | Critical assets are known by technology teams but not consistently recorded in a central register. | Incomplete control scope |
| Control implementation | Key identity, endpoint, and network controls exist, but evidence is fragmented. | Assurance gap |
| Testing control effectiveness | Testing is performed through projects and audits, but a risk-based control testing calendar is not fully documented. | Governance gap |
| Incident management | Incident response process exists, but regulatory notification decision records should be standardised. | Regulatory response |
| Third-party security | Material suppliers are reviewed, but assurance evidence needs clearer refresh dates and ownership. | Supplier risk |

## Recommended Next Steps

1. Confirm critical information asset register ownership.
2. Map key controls to CPS 234 obligations and evidence owners.
3. Create a quarterly evidence refresh cycle.
4. Standardise incident notification decision records.
5. Prioritise third-party assurance for material service providers.
